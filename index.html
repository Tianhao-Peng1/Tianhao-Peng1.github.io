ADMIRE 课题组

ADMIRE（Adaptive Distributed Multi-agent Intelligence via Recursive Evolution）是北京航空航天大学复杂关键软件环境全国重点实验室的研究团队。课题组负责人为 吴文峻教授。

我们研究复杂环境中的自适应多智能体系统，关注智能体如何记忆、学习、推理、协作和持续演化。研究涵盖用于智能体协作与受控递归自改进的软件基础设施、无人机与机器人的具身群体智能，以及理论、计算与实验智能体协作的科学发现。

课题组与依托平台

ADMIRE 课题组依托北京航空航天大学复杂关键软件环境全国重点实验室开展研究。

课题组研究方向

课题组以软件空间的 RSI 基座与治理为底座，贯通物理／具身空间和科学发现空间，形成面向复杂环境的自适应智能体群体关键技术与系统框架。

软件空间 群体智能体的基座与治理

以 Agentic Mesh 组织智能体协作，支持受控的递归自改进。

研究要点

为软件、具身与科学发现空间中的智能体与服务提供统一的运行与治理基座（Agentic Mesh），并以隔离实验、独立评测和渐进发布实现受控的递归自改进（RSI）。

  • Agentic Mesh 治理：运行时、生命周期、网关、遥测、记忆与编排，统一接入群体 Agent 与 Service。
  • 受控自改进：在隔离沙箱中生成并评测候选版本，先过约束、再独立复评，渐进发布且可回退。
  • 领域智能体：服务组合、微服务根因定位与智能运维，作为基座上的典型应用持续演化。
Agentic Mesh RSI 基座 RCA Agents

物理空间 具身群体智能

研究无人机和机器人的协同控制、路径规划与实物验证。

研究要点

面向无人机、机器人和无人系统，把大模型的高层认知与多智能体强化学习、物理先验、安全约束和真实环境反馈结合起来。

  • 从稳定控制、团队共识到路径规划与空间推理，支撑可部署的多机器人协作。
  • 利用对称性、势场、Lyapunov 稳定性等数学物理先验提升训练效率与安全性。
  • 用 LLM 智能体自动生成奖励、组织训练、封装模型并推动仿真到真实迁移。
UAV Swarm MARL Sim-to-Real

科学发现空间 Agentic Scientist

让理论、计算与实验智能体协作，支持科研自动化。

研究要点

把科学问题转化为可验证的智能体工作流，让理论、计算、实验和反馈形成闭环，支撑科学计算、AI4Sci 与实验自动化。

  • Scientific Theory、Computing、Experiment Agents 分工协作，完成文献、假设、仿真和实验设计。
  • 面向 PDE 求解、流体仿真等任务，构建检索、计划、代码生成、执行与纠错闭环。
  • 结合 ScienceOS、智能计算平台和机械臂/多模态实验设备，探索可复现的科研自动化。
ScienceOS AI4Sci PDE Agents

复杂关键软件环境全国重点实验室

实验室面向国家重大需求，以支撑大型复杂装备和空天地实时系统的复杂关键软件为研究对象，围绕开发效率、质量保障与持续演化等关键问题开展研究。

重点研究方向包括：复杂系统机理及软件理论、群体智能与群体软件工程、软件可信保障与质量评估、软件运行支撑与持续演化。
